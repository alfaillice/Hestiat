# Hestiat V29 — Visual System & UX Polish

V29 unifies the visual language across the public experience and applies the Hestiat principles: warm, human, calm, premium, transparent and mobile-first.

## Design direction
- Ivory / sand / natural stone surfaces
- Deep forest / graphite text and actions
- Editorial serif display typography paired with clean UI typography
- Moderate radii, restrained borders and shadows
- Large accommodation photography
- No neon, excessive gradients or glassmorphism
- Strong whitespace and clear hierarchy
- Search and checkout remain decision-focused

## Primary journey
Home → Results → Listing → Checkout → Confirmation → My trip → Account

## Host journey
Host dashboard → New listing → Preview → Publish → Calendar → Channels

## V29 principle
The interface exposes decisions, not system complexity. Channel sync, payment state, availability and operations remain behind simple status-driven UI.
