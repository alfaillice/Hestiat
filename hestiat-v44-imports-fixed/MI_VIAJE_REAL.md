# Hestiat — Mi viaje real

`/mi-viaje` ahora consume `/api/auth/bookings` y muestra la reserva real del huésped:
- alojamiento y portada;
- fechas;
- huéspedes;
- estado;
- número de reserva;
- anfitrión;
- precio total;
- timeline del viaje;
- capa Hestiat IA preparada para usar datos reales.

La IA todavía es interfaz/concepto: no se debe responder con información inventada. La siguiente integración debe alimentarla con listing + booking + reglas + check-in + mensajes.
