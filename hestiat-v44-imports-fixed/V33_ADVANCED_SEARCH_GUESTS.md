# Hestiat V33 — Búsqueda avanzada + huéspedes

V33 conecta destino, fechas, huéspedes y filtros con disponibilidad real del servidor.

## Reglas
- Solo se muestran alojamientos publicados con capacidad suficiente.
- Si se indican fechas, se respetan estancia mínima y antelación configurada.
- Se excluyen bloqueos manuales, reservas internas activas y reservas externas activas.
- Precio mínimo/máximo se filtra en servidor.
- El frontend mantiene todos los parámetros en la URL para compartir/repetir una búsqueda.
- El checkout continúa siendo la autoridad final: la búsqueda nunca garantiza una reserva.

## UX
El buscador principal permite elegir destino, entrada, salida y número de huéspedes. En resultados, los filtros se pueden ajustar sin perder el contexto de búsqueda.
