# Hestiat IA — Tools V2

Hestiat IA evoluciona de FAQ a asistente operativo contextual.

## Tools
- `get_trip_details`: datos verificados de reserva y alojamiento.
- `get_checkin_instructions`: horario, dirección, reglas y datos de acceso disponibles.
- `contact_host`: crea una solicitud para contacto humano con el anfitrión.
- `create_support_request`: abre incidencia Hestiat por categoría.

## Regla de seguridad
Las herramientas solo operan sobre la reserva del huésped autenticado. IA no puede inventar datos ni modificar pagos/reservas. Las acciones sensibles futuras requerirán confirmación explícita.
