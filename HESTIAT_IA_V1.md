# Hestiat IA V1

La primera capa funcional de Hestiat IA ya responde usando datos reales del booking y listing.

Contexto disponible:
- fechas y huéspedes;
- dirección;
- horario de check-in;
- reglas estructuradas;
- anfitrión.

La API evita inventar datos: si un dato no está registrado, lo indica.

Siguiente evolución:
- modelo LLM con herramientas/funciones;
- recomendaciones basadas en ubicación;
- check-in instructions;
- mensajes huésped-anfitrión;
- escalado humano;
- WhatsApp y email.
